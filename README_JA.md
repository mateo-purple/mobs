# FRIEND MONSTERS — 日本語導入・操作ガイド

Minecraft の敵Mobを仲間にして、追尾・待機・巡回、戦闘援護、取引などを行う MOD です。専用の管理画面は追加せず、取引にはバニラの村人取引画面を使います。

## 対応環境と導入するファイル

| 項目 | 対応版 |
| --- | --- |
| Minecraft | **Java版 1.21.11** |
| MODローダー | **NeoForge 21.11.45** |
| Java | **21** |
| MOD | FRIEND MONSTERS `0.1.0-alpha.1` |

導入するファイルは `build/libs/friend-monsters-neoforge-1.21.11-0.1.0-alpha.1.jar` です。`-sources.jar` は開発用のソースで、ゲームには入れません。Bedrock版、Fabric、別バージョンのMinecraftには対応しません。

マルチプレイでは**サーバーと参加する全員のクライアントに、同じ版のこのJAR**を入れてください。

## 初めて導入する場合

1. Minecraftとサーバーを終了します。既存ワールドを使う場合は、先に下記のバックアップを行います。
2. Minecraft LauncherでJava版 **1.21.11** を一度起動して終了します。
3. **NeoForge 21.11.45** のインストーラーを用意し、Java 21で実行して `Install client` を選びます。
4. LauncherでインストールされたNeoForgeの起動構成を選び、一度起動して終了します。
5. その起動構成のゲームディレクトリにある `mods` フォルダへ、上記の通常JARをコピーします。`mods` がなければ作成します。
6. NeoForgeの起動構成で起動します。タイトル画面のMOD一覧で **FRIEND MONSTERS** を確認し、最初は新規ワールドで操作を試してください。

Windowsの標準ゲームディレクトリは `%APPDATA%\.minecraft` です。起動構成に独自のゲームディレクトリを指定した場合は、そのディレクトリの `mods` を使います。Minecraft本体のJARを直接書き換える必要はありません。

専用サーバーではNeoForge 21.11.45を `Install server` で導入し、サーバーディレクトリの `mods` に同じJARを置きます。Java 21でNeoForgeサーバーを起動してください。

### ワールドのバックアップ

ゲームを終了した状態で、ゲームディレクトリの `saves` にある対象ワールドのフォルダを丸ごと別の場所へコピーします。専用サーバーは停止してから、ワールドのフォルダと `config` をコピーします。このMODの設定ファイル `config/friendmonsters.json` も保存しておくと設定を戻せます。

既存ワールドへ初めて導入する前、MODを更新する前、取り外す前にバックアップしてください。以前の状態へ戻す場合はバックアップしたワールドと対応するMOD・設定を一緒に戻します。

## 基本操作

餌や仲間化用アイテムは**メインハンド**に持ち、対象へ右クリックします。条件を満たした抽選は成功・失敗にかかわらず原則1個消費します。HPや装備などの必要条件を満たさない場合は消費しません。成功時はハート、失敗時は煙が出ます。

| 対象・操作 | 結果 |
| --- | --- |
| 通常の仲間を素手で右クリック | **追尾 → 待機 → 巡回 → 追尾** |
| 仲間ピリジャーを通常右クリック | バニラ取引画面を開く |
| 仲間ピリジャーをスニーク＋素手右クリック | **追尾 ↔ 解散** |
| 一時停戦中のヴィンディケーター・ウィッチ・エヴォーカーを通常右クリック | バニラ取引画面を開く。独立した行動命令はありません |
| 仲間ドラゴンをエンドで素手右クリック | 騎乗 |
| 仲間ドラゴンをスニーク＋素手右クリック | 追尾・待機・巡回を変更 |
| 対応する餌・弾薬・装備・ポーションを持って右クリック | アイテムの受け渡しを優先 |

追尾中は所有者が攻撃した相手、所有者を攻撃した相手へ援護し、遠く離れると帰還します。待機は指示した場所から動かず、巡回は周辺を歩きながら敵を探します。ホグリンには行動命令がありません。

所有者・仲間への誤射を防ぎますが、野生の敵は仲間を攻撃できます。**ウォーデンだけは所有者以外のMobを敵味方の区別なく攻撃**するため、ほかの仲間と同じ場所で運用する際は注意してください。日光燃焼、猫への恐怖、飛行、水中適性などの生態は各Mobに残ります。

「動物の生肉」は**生の牛肉・豚肉・鶏肉・羊肉・兎肉**です。腐った肉や魚は含みません。「食料」は通常の食べ物として扱われるアイテムです。

### 装備・弾薬・ポーション

ゾンビ系・スケルトン系・ピグリンには対応する武器・防具を右クリックで渡せます。元の装備は所有者へ返します。スケルトン系の武器は同時に複数使えません。

スケルトン系の効果付き矢は同じ種類を最大64本保管します。別の効果付き矢に替える場合は以前の矢を返します。蜘蛛系には通常・スプラッシュ・残留ポーションを渡せます。洞窟蜘蛛に回復や強化のポーションを渡すと、噛んだ敵にもその効果が付きます。

溶岩バケツを消費すると空のバケツを返します。通常のポーションを消費するとガラス瓶を返します。

### 邪悪な村人との停戦と取引

直接仲間にできるのはピリジャーだけです。追尾中の仲間ピリジャーの周辺にいるヴィンディケーター・ウィッチ・エヴォーカーも一時的に友好となります。範囲を離れれば一時停戦は終了し、**陣営の誰か1人でも攻撃された場合は、その陣営全員が敵へ戻ります**。ピリジャーは村人側のアイアンゴーレムから狙われます。解散したピリジャーは離れると自然デスポーンできます。

取引は個体ごとに内容が異なり、**Minecraft内の1日（24,000tick）ごと**に更新されます。同じ日の取引内容・実際のエンチャント・使用回数は保存され、取引画面を開き直しても在庫は復活しません。翌日の更新で新しい品揃えになります。

| 商人 | 主な取引 |
| --- | --- |
| ピリジャー | 複数ランクのランダムアイテム販売。食料・通常の矢・クロスボウの買い取り |
| ヴィンディケーター | 素材別の剣・斧・防具の販売、素材の買い取り |
| ウィッチ | ポーション・ドラゴンブレスの販売など |
| エヴォーカー | 高額の不死のトーテム、実際にエンチャントされた本、不吉な瓶など |

安価な取引にはエメラルド、高ランクにはエメラルドブロックやダイヤを使います。価格と品揃えは個体・日によって異なります。

### エンダーマンの報酬

追加のエンダーアイ1個につき報酬を1回生成します。既存のブロックやチェストから盗む処理は行いません。宝箱の中身はバニラの戦利品テーブルで新規生成します。報酬を置くため、周囲に地面と空いた場所を用意してください。

| ランク | 報酬 | 初期の出現割合 |
| --- | --- | --- |
| 1 | 石・土・木などの通常ブロック | 70% |
| 2 | 鉱石ブロック | 20% |
| 3 | 廃坑・ダンジョン・砂漠の寺院・ピリジャー前哨基地などの戦利品チェスト | 8% |
| 4 | ダイヤブロックなどの鉱物ブロック | 1.8% |
| 5 | エンドシップ級（エンドシティ）のお宝チェスト | 0.2% |

### ドラゴン騎乗

エンドで仲間ドラゴンに素手右クリックして乗ります。移動キーを変更している場合は、そのキー設定を使います。

| 操作 | 動作 |
| --- | --- |
| WASD | 視線方向を基準に移動 |
| マウスの視線 | 飛行方向を変更 |
| ジャンプ（標準：Space） | 上昇 |
| ダッシュ（標準：Ctrl） | 下降 |
| 左クリック | ドラゴン火球 |
| 右クリック | ドラゴンブレス |
| スニーク（標準：Shift） | 降りる |

## 設定ファイル

初回起動でゲーム／サーバーディレクトリの **`config/friendmonsters.json`** が生成されます。ゲーム／サーバーを停止してから編集し、再起動すると反映されます。専用の設定GUIはありません。マルチプレイの仲間化・AIなどの設定はサーバー側で決まります。

`recruitmentChance` はMobの英語IDと確率を対応させた項目です。例えば `"creeper": 0.05` は5%です。0～1の値で指定します。ドラゴンの確率、ウォーデンのHP連動抽選、ウィザーのHP条件などはコード側の専用ルールです。

| 設定名 | 初期値 | 意味 |
| --- | --- | --- |
| `patrolRadius` | 16 | 通常の巡回索敵範囲 |
| `groupRadius` | 24 | ピグリン／ガーディアンの瞬間加入、邪悪な村人の停戦範囲 |
| `followTeleportDistance` | 40 | 追尾中に帰還する距離 |
| `witherReturnDistance` | 40 | ウィザーが帰還を優先する距離 |
| `elderCurseRadius` | 24 | エルダーガーディアンの呪い範囲 |
| `elderCurseDurationTicks` | 700 | 呪いの持続時間（約35秒） |
| `magmaDecayTicks` | 600 | オーバーワールドのマグマキューブ縮小間隔（約30秒） |
| `endermanDepartureTicks` | 1200 | エンダーマンの取引なしでの退出時間（約1分） |
| `endermiteSpawnIntervalTicks` | 200 | エンダーマイトの出現補助抽選間隔（約10秒） |
| `endermiteSpawnChance` | 0.15 | その出現補助抽選の確率 |
| `dragonFlightSpeed` | 0.9 | 騎乗中の飛行速度 |
| `creeperThrownTntPower` | 2.5 | 投げたTNTの爆発威力 |
| `caveSpiderStartingHp` | 8 | 仲間化した洞窟蜘蛛の初期最大HP |

時間は通常のゲーム速度で20tick＝約1秒です。ブレイズの巡回索敵60ブロック、TNT最大128個などの種別固有ルールは、通常設定より優先されます。

所有者、行動モード、弾薬、強化、ポーション、報酬の保留分、取引内容と在庫、シュルカーの保管品はワールドとともに保存されます。

## 開発用ビルド

ソースは `src/main/java/dev/friendmonsters`、リソースは `src/main/resources` にあります。Java 21の環境でこのプロジェクトのGradleから `build` を実行すると、`build/libs` に通常JARとソースJARが出力されます。

## 今回の確認状況

**ビルド・ゲーム起動スモークの最終結果は確認中です。納品時に実際のログに基づいて、この欄を更新します。** `compileJava` やMinecraft開発用アーティファクトの生成成功だけを、MOD全体の動作確認とは扱いません。

このガイドの機能説明は実装と確定仕様に基づきます。実際に確認できたビルド・起動・ゲーム内操作と、未検証の項目は最終確認結果に分けて記載します。
